Webfoundry — The Creative Operating System for the Modern Web

🚀 Vision

Webfoundry exists to make building for the web feel like play again. We're creating a 10× productivity platform for developers, designers, and creators who want to move fast, iterate visually, and collaborate live — without sacrificing code, control, or performance.

Where Figma stops at design and VS Code stops at code, Webfoundry fuses design, logic, AI assistance, shell access, and deployment into a single real-time creative canvas. This is the missing bridge between imagination and execution.

⚙️ What It Does

Webfoundry is a browser-native, local-first, multiplayer IDE with an intelligent visual editor powered by Tailwind, Trystero WebRTC, and an optional NodeJS Companion server for filesystem and shell integration.

Creators can:

  • Design responsive UIs visually using intuitive Tailwind classes.
  • Edit real project code and visual editor collaboratively, with full HTML/JS/CSS fidelity.
  • Invoke GPT-5.1 Codex via natural voice to patch HTML elements surgically.
  • Run and deploy instantly to Netlify or export to ZIP, desktop (Tauri), or Android (APK).

It’s like if VS Code, Figma, and Replit had a child — one that speaks Tailwind, syncs over P2P, understands your codebase, and treats UI editing and coding as the same continuum.

💡 The Wedge: Ecstaz

Our wedge is Ecstaz — a simple, beautiful, no-setup static site builder that runs entirely inside Webfoundry. Ecstaz is the “Squarespace for the local-first era,” but with a superpower: you can pause the site → drop into Webfoundry visual edit mode → customize everything → resume instantly.

Ecstaz gives Webfoundry the perfect funnel: normie-friendly onboarding with an instant upgrade path into full creative power.

  • Instant page editing with Tiptap and live theme switching.
  • Local storage persistence or full file-system backed editing inside Webfoundry.
  • Export to static HTML, hybrid SPA, or deploy directly from Webfoundry.
  • P2P multiplayer editing out of the box.

Ecstaz and Webfoundry together unlock a new creative workflow: Start simple. Go deep when you're ready. Never switch tools.

🧩 Architecture Advantage

  • Controllers: Modular singletons exposing state and actions globally.
  • P2P Collaboration: Trystero WebRTC mesh syncs edits, selections, and state between peers.
  • Offline-first: LocalForage FS + fetch interception = no backend required.
  • Service Worker Routing: Per-tab app isolation and fast reloads.
  • AI Native: Integrated GPT-5.1 Codex via voice for context-aware code and UI patching.
  • Composable Platform: Ecstaz, slide-deck builders, resume builders, and visual novel engines can all run on top of Webfoundry.

This isn’t a toy or a static site builder — it’s a creative operating system for everything from landing pages to full-stack applications.
